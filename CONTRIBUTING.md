# Contributing to tn-noise-learning

Thanks for your interest in contributing to `tn-noise-learning`!

First time contributing to an open-source project? [This guide](https://opensource.guide/how-to-contribute/) is a
good start.

## How to contribute

- Report bugs and suggest features through [issues](https://github.com/Algorithmiq/tn-noise-learning/issues).
- Ask questions in [discussions](https://github.com/Algorithmiq/tn-noise-learning/discussions).
- Improve the code, tests or documentation through pull requests.

The [developer guide](https://algorithmiq.github.io/tn-noise-learning/contributing/) explains how to set up the
development environment, run the checks, and what a pull request needs.

## Contributor License Agreement (CLA)

External contributions are accepted under the Individual CLA in [CLA.md](CLA.md). In plain language: you confirm that
you have the right to submit your contribution and you allow the project maintainers to use and redistribute it under
the project licence. Opening a pull request confirms that you agree to the CLA.

If you are contributing on behalf of your employer, contact [cla@algorithmiq.fi](mailto:cla@algorithmiq.fi) to arrange
a Corporate CLA.

## Code of Conduct

Please read and follow the [Code of Conduct](CODE_OF_CONDUCT.md). It applies to all interactions in this repository,
including issues and pull requests.
