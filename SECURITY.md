# Security Policy

## Reporting a Vulnerability

Report a potential security issue privately through GitHub's security advisories:

https://github.com/Algorithmiq/tn-noise-learning/security/advisories/new

Please do not open a public issue about a potential security vulnerability.

More details on the feature are in
[GitHub's guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
